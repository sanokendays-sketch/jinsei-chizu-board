# 人生地図ボード

無限キャンバスに「思い出カード」を並べて、地図と年表で自分史をつくるアプリ。
費用はかかりません（Excalidraw・Leaflet・国土地理院の地理院タイル・GitHub Pages）。

公開先：https://sanokendays-sketch.github.io/jinsei-chizu-board/

## できること

### ① ボード（キャンバス）
- 「＋ 思い出」でカードを追加（年・月・日・タイトル・場所・写真・メモ）
- カードをタップすると下に「✏️ このカードを編集」
- 手書き・図形・矢印など、Excalidrawの機能はそのまま使える
- ブラウザ(IndexedDB)に自動保存。右上「⋯」の点が緑なら保存済み

### ② 地図
- 上の「🗾 地図」。場所の入ったカードがピンで並び、年の順に点線でつながる
- 同じ場所のカードはひとつのピンにまとまる（数字が枚数）
- カード入力の「🗾 地図で場所を選ぶ」→ 住所で探す → 地図をタップ／ピンをずらして決定
- 住所検索：国土地理院の検索（長期提供の保証なし）→ 4秒で応答がなければ OpenStreetMap(Nominatim)

### ③ あの頃の空
- 地図画面の左下「🕰 あの頃の空」で、国土地理院の年代別空中写真を重ねる
  （1936〜42年ごろ／1945〜50年 米軍撮影／1961〜69年／1974〜78年／1979〜83年／1984〜86年／1987〜90年／現在）
- ピンの「🕰 この頃の空」：カードの場所で実際に写真がある年代のうち、カードの年に一番近いものを自動で選ぶ
- 場所を選ぶ画面でも昔の写真に切り替えられる（昔の家を探すときに便利）
- 1974〜78年と1961〜69年は広く、それ以外は地域によって写真がないことがある

### ④ 年表・テンプレート・書き出し
- 「📅 年表」：年代ごとに縦に並ぶ。人生系のボードでは年齢も出る
  （「生まれた年」を入れるか、タイトルに「誕生」「生まれ」を含むカードから自動で読み取る）
- 「⋯」→「📚 ボード」：ボードを何枚でも持てる。新しいボードはテンプレートから
  - 🗺️ 人生地図／👵 親の人生 聞き書き／🧳 旅の記録／🏘️ 町の思い出マップ／🚶 おでかけ計画
  - テンプレートで変わるのは、言葉・カードの色・年齢表示の有無だけ。仕組みは全部同じ
- 「⋯」→「📤 書き出す・印刷する」
  - 🖼 ボードを画像(PNG)で
  - 📅 年表を印刷（印刷画面で「PDFとして保存」）
  - 📝 年表を文章で（コピーしてLINEやメール、AIへの相談に貼れる／.txtファイル）
- 見本の人生（架空の人物・12枚）：白紙のボードやメニューから入れられる。写真はこのアプリのために描いたイラスト（`src/samplePhotos.js`）で、実在の写真は使っていない。書き換えたカードは自分のカードになり、「見本を消す」で残りをまとめて消せる
- バックアップ(JSON)の保存・読み込み。読み込みは「新しいボードとして追加」か「今のボードと置き換え」

## データのしくみ（汎用化の鍵）

カード1枚 = 枠(rectangle) + 文字 + 写真 のグループ。
枠の `customData` にカードの中身をすべて持たせています。

```js
{ kind: "memory", v: 1, cardId, year, month, day, title, place, note, fileId, lat, lng }
```

地図画面・年表・書き出しは、この `customData` を読むだけで作っています。

保存（IndexedDB / idb-keyval）：

| キー | 中身 |
| --- | --- |
| `jinsei:boards` | ボードの目次 `{ current, boards: [{ id, title, templateId, cards, updatedAt }] }` |
| `jinsei:board:<id>` | ボード1枚分 `{ elements, files, appState, meta: { birthYear } }` |
| `jinsei-board:v1` | ①〜③時代の保存データ。初回に「私の人生地図」へコピーし、元は消さずに残す |

## 動かし方

```bash
npm install
npm run dev      # 開発用サーバー
npm run build    # dist/ に本番用ファイルができる
```

`main` に push すると GitHub Actions がビルドして GitHub Pages に公開します。

`npm run build` のたびに Excalidraw のフォントが `public/fonts` にコピーされます
（外部CDNに頼らないため）。日本語の手書き風フォント(Xiaolai, 約13MB)を入れたいときは
`INCLUDE_CJK_FONT=1 npm run build`。

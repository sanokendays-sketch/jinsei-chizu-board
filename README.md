# 人生地図ボード

無限キャンバスに「思い出カード」を並べて、自分史をつくるアプリ。
キャンバスは Excalidraw（MITライセンス）。費用はかかりません。

## いまできること（①）

- 「＋ 思い出」でカードを追加（年・月・タイトル・場所・写真・メモ）
- カードを選んで「✏️ 編集」で書き直し・削除
- 「📜 一覧」で年の順に並べて、タップでそのカードへ移動
- 手書き・図形・矢印など、Excalidrawの機能はそのまま使える
- ブラウザ(IndexedDB)に自動保存
- メニューからバックアップ(JSON)の保存・読み込み

## ②でできるようになったこと

- 左上の「🗾 地図」で地図画面に切り替え。場所の入ったカードがピンで並ぶ
- 同じ場所のカードはひとつのピンにまとまる（数字が枚数）
- 年の順に点線でつなぐ（「線を消す」で消せる）
- ピンをタップ → 「ボードで見る」「編集」
- カード入力の「🗾 地図で場所を選ぶ」→ 住所で探す → 地図をタップ／ピンをずらして決定
- 地図は 淡色地図・標準地図・写真（現在）を右上で切り替え

地図：国土地理院 地理院タイル（出典を常に表示）。
住所検索：国土地理院の検索（長期提供の保証はなし）→ 使えないときは OpenStreetMap(Nominatim)。

## データのしくみ（汎用化の鍵）

カード1枚 = 枠(rectangle) + 文字 + 写真 のグループ。
枠の `customData` にカードの中身をすべて持たせています。

```js
{ kind: "memory", v: 1, cardId, year, month, day, title, place, note, fileId, lat, lng }
```

今後はここに `tags`（テンプレート）などを足していきます。
地図画面・年表画面は、この `customData` を読むだけで作れます。

## 動かし方

```bash
npm install
npm run dev      # 開発用サーバー
npm run build    # dist/ に本番用ファイルができる
```

`npm run build` のたびに Excalidraw のフォントが `public/fonts` にコピーされます
（外部CDNに頼らないため）。日本語の手書き風フォント(Xiaolai, 約13MB)を入れたいときは
`INCLUDE_CJK_FONT=1 npm run build`。

## GitHub Pages で公開する（無料）

`vite.config.js` は `base: "./"` なので、`dist/` の中身をそのまま置けば動きます。
②で地理院タイル（地図画像）を読み込むには、Claudeのアーティファクトではなく
GitHub Pages などの普通のWebサイトで動かす必要があります。
